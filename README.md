# Спринт Spark

Решения отправляются в сервис проверок `sprint_7_check_service`.

В корневом `settings.py` задайте `STUDENT_ID` — ваш учебный
логин.

Запустите из каталога нужного задания:

```bash
python submit.py
```

Скрипт прочитает `realization.py`, `realization.txt` или `dag.py` рядом с собой —
имя указано в `DEFAULT_SOLUTION` соответствующего `submit.py`.
Решение передаётся как UTF-8 текст; Python-код на стороне клиента не исполняется.
Дополнительные Python-пакеты для отправки не нужны.

В каталогах заданий уже лежат файлы для подготовки ответа:

| Файл | Что подготовить |
| --- | --- |
| `realization.py` | Дополните прекод или TODO своим Python-решением. |
| `realization.txt` | Замените подсказку требуемым выводом, сохранив форматирование. |
| `dag.py` | Подготовьте DAG по условию; при необходимости перенесите свои задачи из предыдущего урока. |

Исключение: в заданиях 4.11.1 и 4.11.2 файл `realization.py` содержит **текст
команды оболочки**, несмотря на расширение. Замените подсказки самой командой.

Заготовки не являются готовыми решениями: перед отправкой заполните TODO,
замените заглушки `None` и `NotImplementedError` и проверьте требования урока.
Готовый прекод, уже имеющийся в репозитории, тоже может требовать дополнения.

Для DAG-заданий (4.12.1, 5.2.5, 5.3.6) заполните соседний `dag.py` и выполните
`python submit.py`.

Дождитесь ответа. При успехе скрипт выведет сообщение с секретным кодом,
который нужно ввести на платформе. При ошибке решения — пояснение проверки.
Код завершения `0` означает успешную проверку, `1` — ошибку или недоступность.
Предел ожидания ответа — 300 секунд; при тайм-ауте можно повторить отправку.

Для проверки общего клиента: `python -m unittest discover -s tests -v`.
